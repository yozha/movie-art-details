# Fonts

`movie-art-plugin/src/main/res/font/`: Roboto 2.138 (Google, Apache License 2.0), unmodified. The files
are renamed to satisfy Android resource naming rules.

Source: https://github.com/googlefonts/roboto-2/releases/download/v2.138/roboto-android.zip
(the official googlefonts repository). Roboto 3.x is released under the SIL OFL 1.1, so the last
Apache 2.0 release is used. Glyph coverage was checked against the font's cmap table: Latin, the full
Cyrillic block, and common punctuation such as the en dash, ellipsis, and middle dot.
